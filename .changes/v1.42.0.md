## v1.42.0 - 2026-10-26

- _ci-and-build_: Update changie to newest format. Golangci-lint config file is also now converted to the latest.
- _new-product-feature_: Add support for multiple Azure MSI profiles. When selecting Azure as the profile auth-provider the user is prompted to enter the clientID for the MSI (managed identity) they would like to use for this profile. The clientID is stored in the profile config file i.e. .dsv.yml.
  the clientID is retrieved from the config when ever azure authentication is required.
- _tests_: Integration tests skip the crypto-\* cases: the DSV crypto API (EaaS) is intentionally disabled server-side (API Gateway 403 mock on dev and all prod regions) after a security finding, so those cases can only fail.
- _security_: Changed sha1 function calls to sha256.
- _security_: Improve security by removal of empty httpWriter in OIDC auth, and increasing to 2048 bit encryption in PKI generation.
- _security_: Removed high level snyk issues for hard coded credentials.
- _security_: Modified vars to bring into compliance with CWE-798: Use of Hard-coded Credentials.
- _security_: Go toolchain 1.24.1 → 1.26.8 and dependency upgrades (gRPC 1.83.2, golang.org/x/net 0.59.0, x/text, x/crypto, aws-sdk-go-v2 service/s3 1.113.4) clear all 52 Snyk findings, including 2 CRITICAL; govulncheck reports no reachable vulnerabilities.
- _security_: Go toolchain 1.26.8 → 1.26.10 fixes CVE-2026-56857, a Critical Go standard library vulnerability on Windows; golang.org/x/net 0.59.0 → 0.60.0 fixes five HTTP/2 vulnerabilities that govulncheck found reachable. govulncheck now reports no reachable vulnerabilities.
- _dependencies_: Updated go-autorest to latest version
- _dependencies_: Maintenance release due to updated dependencies.
